# 기획서 빌더

사내 기획서(게임 상세 기획서 유형)를 만드는 **Notion 스타일 블록 에디터**입니다.
하나의 문서를 **문서형(A4 세로)** 과 **슬라이드형(16:9 자유 캔버스)** 두 가지로 만들 수 있습니다.

> Claude Design 핸드오프 번들(`-B4FgHuSjs__GooBhYeZag`)을 작업 폴더로 그대로 구현한 결과물입니다.

## 실행 방법

이 앱은 브라우저에서 JSX를 변환(Babel standalone)하므로 **HTTP로 서빙해야** 합니다.
`index.html` 파일을 더블클릭(`file://`)하면 브라우저 보안 정책 때문에 동작하지 않습니다.

### 가장 쉬운 방법
프로젝트 폴더의 **`serve.bat` 더블클릭** → 브라우저에서 자동으로 `http://localhost:8000` 열림.

### 수동 실행
```powershell
# 이 폴더에서
python -m http.server 8000      # 또는:  npx serve -l 8000
# 브라우저에서 http://localhost:8000 접속
```

## 주요 기능

### 라이브러리
- 여러 문서 생성 / 복제 / 삭제, 브라우저(localStorage) 자동 저장
- 새 문서 만들 때 **문서형 / 슬라이드형** 선택

### 문서형 (A4 세로)
- **표지** — 분류 태그(신규개발·수정 / 컨텐츠·이벤트·유료화), 소속·작성자·작성일, **문서 변경 이력 표**
- **자동 목차** — 점선 리더 + 정확한 페이지 번호 (레벨 깊이 선택)
- **계층형 섹션** — `1 > 1 > A > • > –` 번호 자동 부여, 들여쓰기/내어쓰기
- **데이터 표**(변수명·변수형·설명), **이미지/자리표시자**, **안내·경고 콜아웃**
- **마크다운** — `**굵게**` `*기울임*` `` `코드` `` `~~취소선~~` `==형광==` `[링크](url)`
- 대제목(레벨 1)마다 **A4 페이지 자동 구획**, 미리보기 = A4 페이지네이션
- 블록 단위 **Ctrl+C / X / V**, 인라인 편집, 드래그 재정렬

### 슬라이드형 (16:9 자유 캔버스)
- PowerPoint/Figma식 **자유 배치** — 요소 선택·이동·크기조정(8방향 핸들)
- **다중 선택**(Shift·드래그박스) + 정렬·균등 분배 + **스마트 가이드/스냅**
- **요소** — 소제목·항목·내용·텍스트·표·이미지·도형(사각형·원·선·화살표)·콜아웃
- **표 편집**(셀 더블클릭, 행/열 추가·삭제), **텍스트 서식 바**(정렬·크기·굵게·기울임·글꼴·줄간격·글자색·강조색)
- **목차 슬라이드** — 번호 문법(1→1→A→•) 들여쓰기, 대제목+소제목 그룹 유지·균등 분배, 깊이 토글, 넘치면 폰트 자동 축소
- **슬라이드 썸네일 레일**, 발표자 노트, 슬라이드 번호 토글, 배경/테마 전환
- 요소 단위 **Ctrl+C / X / V**, **이미지 붙여넣기**, **Ctrl+Z / Ctrl+Shift+Z**(실행취소/다시실행)
- 문서↔슬라이드 **동기화 배지**(아웃라인 변경 시 "다시 생성" 알림)

### 내보내기
- **PDF** (Cmd/Ctrl+P) — 문서형 A4 세로 / 슬라이드형 16:9 풀블리드
- **PPTX**(편집 가능), 슬라이드별 **PNG**
- ※ PDF는 인쇄 대화상자에서 "배경 그래픽" 옵션을 켜야 표 헤더·강조 색이 출력됩니다.

## 구조

```
index.html          진입점 — 폰트/CDN(React·Babel·pptxgenjs·html2canvas) + src 로드
styles.css          전체 스타일·디자인 토큰 (A4/슬라이드/캔버스/인쇄 규칙)
src/
  store.js          데이터 모델, 블록 팩토리, 샘플 문서(키레노스 기사단 수색대)
  numbering.js      계층 섹션 번호 엔진 (1 > 1 > A > • > –)
  markdown.js       인라인 마크다운 파서
  icons.jsx         공용 아이콘
  blocks.jsx        블록 렌더러 + 인라인 편집 + 마크다운/이미지 컨트롤
  cover.jsx         표지(분류 태그·변경 이력 표)
  toc.jsx           자동 목차
  editor.jsx        문서형 에디터(대제목별 A4 구획, 블록 클립보드)
  paginate.jsx      A4 페이지네이션 미리보기
  slides.jsx        슬라이드 빌드 로직(타이틀·아젠다·구분·내용)
  canvas-core.jsx   자유 캔버스 코어(좌표·선택·스냅 유틸)
  canvas-elements.jsx 캔버스 요소 렌더러(텍스트·표·이미지·도형)
  canvas-deck.jsx   자유 캔버스 덱 컨트롤러(멀티선택·정렬·키보드·툴바·레일)
  exports.js        PPTX/PNG 내보내기
  app.jsx           앱 셸(라이브러리·상단바·편집↔미리보기·undo/redo·PDF)
```

## 기술 메모

- 빌드 단계 없이 **브라우저에서 Babel standalone** 으로 JSX를 변환합니다(프로토타입 방식).
  파일 수정 후 새로고침만 하면 반영됩니다.
- 프로덕션(번들링·빠른 로딩)이 필요하면 Vite + React로 마이그레이션할 수 있습니다.
  (현재는 모듈이 전역 스코프를 공유하는 구조라, 마이그레이션 시 import/export 정리가 필요합니다.)
